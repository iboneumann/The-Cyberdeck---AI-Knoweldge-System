## Introduction to the first real Cyberdeck  

The Cyberdeck - AI Knoweldge System  

Until here Cyberdecks are in reality small hobby projects for funny looking little hand held DIY computers usually based on a RaspberryPi.  
They were outperformed by even cheap refurbished Laptops and had no real use case.  

Then I needed, finding myself inbetween jobs until reaching legal retirement age, an occupation right when LLM AI models were released to  
the Open Source community. While others started to build pipelines to the large online models, open source uses cases for the reasoning  
models being suitable for data analytics are still rare as much as real Cyberdecks.  

Cyberdecks are part of the dystopian Sci-Fi world and portable super computers used by Deckers that enter the Matrix on their Shadowrun   
called adventures.  

The closest to that is a high-end laptop or a Beowulf Cluster. Beowulf Clusters are supercomputers based on standard hardware like  
standard office computers and LAN hubs. Using MPICH and Linux operating systems on each node called part of the network that forms  
the Beowulf Cluster the CPUs of the Computer Cluster can share workload comparebale to multi-core processors that were develped  
later than the MPICH communication libraries used to create these supercomputer clusters.  
This being said, do they in general need software developed to take advantage of parallel processing which is the dedicated use case  
of large Beowulf Clusters in usually Universities and research labs, but some parts of Linux are able to use an installed MPICH layer  
such as ffmpeg which is used to turn music projects or wav files into mp3. This means that for some uses cases a set of refurbished  
office computers is both cheaper, faster and more efficient than a gaming PC especially if the style to work is changed to parallel  
use of computers. While on a fast, but expensive PC, two or several hardware intensive applications can run and become very slow on  
on older less powerful models, they can run well on two computers linked in a LAN. Depending on the software and which operating system  
libraries they use, the CPU load will be shared on heavy tasks having set up the MPICH Beowulf layer.  

Cyberdecks are also AI systems that help the Dystopian Hacker, the Decker, to enter into bad corporate world computer systems to steal  
data or fight for freedom.  

The next step is obvious. A lot of time, little money, a childish drive for a home build supercomputer and AI reasoning models out for  
download:  

The Cyberdeck Nexus AI Knowledge System.  

From here this website is about an Ollama model use case based on low cost hardware within a LAN assembling a Beowulf Cluster. Next to the  
Beowulf Cluster created using MPICH architecture, a Python 3.10+ environment is set and appropriate to the RAM Ollama models are installed  
to create a practical Cyberdeck.  

By getting deeper into the Ollama tool and LLM AI capabilities the Cyberdeck became a Knowledge System utilizing AI models in different   
ways at the same time. The first way is to talk about data. That part is the Obsidian-Deck which is a set of Python scripts next to   
Obsidian, an advanced Linux note software, being a Knowledgebase system in a Terminal session.  

This way I can sort by Keywords my DeepSeek Chats and reason with a local AI about it.  

The other part is a local AI RAGed with dedicated content such as the DeepSeek chats, a wiki dump file content, Open Library books and   
web site content.
